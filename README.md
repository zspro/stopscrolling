# 放下手机 StopScrolling

一个开源的安卓防沉迷 / 屏幕时间管理工具：给刷不停的应用设限额，超限自动拦截，帮你放下手机。

> 本项目为**原创开源实现**，灵感来自同类屏幕时间管理应用。与任何商业应用无关，不含闭源 SDK，不收集任何数据。

## 功能

- **今日屏幕时间仪表盘** — 基于 `UsageStatsManager` 统计各应用当日使用时长
- **受管应用限额** — 为任意应用设置每日使用分钟数，进度条实时显示用量
- **守门拦截** — 通过无障碍服务监听前台应用切换，受管应用超过当日限额时自动弹出全屏拦截页（呼吸动画 + 冷静倒计时 + 随机语录 + 「放下手机」按钮，每日一次「再刷 5 分钟」机会）
- **宽限期自动续拦** — 「再刷 5 分钟」到期后，即使你停留在同一应用也会被再次拦下
- **80% 限额预警** — 用量到达限额 80% 时发送软提醒通知（每应用每天一次）
- **睡觉时段** — 设定时间段（如 23:00–7:00）内所有受管应用一律拦截，无宽限
- **今日使用 Top 5 榜单** — 首页直观展示使用最多的应用
- **权限横幅提醒** — 权限未开齐时首页显眼提示，回到前台自动刷新状态
- **一键添加常见短视频应用** — 抖音 / 快手 / 小红书 / 微信 / B 站
- **专注锁定** — 15 / 25 / 45 / 60 分钟专注时段，期间打开受管应用会触发锁屏（需设备管理员），并附带倒计时通知
- **开机自启与存活** — BootReceiver + 电池优化豁免引导
- **ROM 兼容性（0.3.0）** — 自动识别小米澎湃OS / 华为 / 荣耀 / OPPO·一加·realme / vivo·iQOO，一键直达各厂商「自启动管理」「省电策略」白名单页，跳转失败自动兜底到应用详情页
- **防改时间作弊（0.3.0）** — 系统时间变更时用单调时钟（`elapsedRealtime`）+ 开机次数交叉校验，把时间拨到明天无法重置限额，异常会计入统计并在首页提示
- **守护自愈（0.3.0）** — AlarmManager 周期自检无障碍服务存活，被系统杀掉后发高优先级通知提醒重新开启，点击直达设置页

## 权限说明

| 权限 | 用途 |
|---|---|
| 用量统计 (PACKAGE_USAGE_STATS) | 统计应用使用时长 |
| 无障碍服务 | 检测前台应用切换，触发拦截 |
| 悬浮窗 (SYSTEM_ALERT_WINDOW) | 在其他应用之上弹出拦截页 |
| 设备管理员 | 专注模式一键锁屏 |
| 忽略电池优化 | 防止服务被系统杀掉 |

本项目**不联网、不读取屏幕内容、不上传任何数据**。

## 构建

Requirements: JDK 17+, Android Studio Ladybug+ (或 Gradle 8.14 + Android SDK 35)

```bash
./gradlew assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

## 使用

1. 安装后进入「设置」，依次开启 5 项权限
2. 回到「首页」，点击「添加应用」或「一键添加常见短视频应用」
3. 为每个应用拖动设置每日限额（默认 30 分钟）
4. 超限后打开该应用即会看到拦截页
